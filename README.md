# RAT
#### Remote computer management without the need to open ports.
### To connect the client and the admin panel, you need a server or open ports; using a server is the simplest approach.

## Minimum server requirements
| Parameter | Meaning |
| :--- | :--- |
| **CPU:** | 1–1.5 cores |
| **RAM:** | 1–4 GB |
| **Storage (ROM):** | 5 GB |
| **Open ports on server:** | 3 |

Approximate cost: 50–100 RUB

### You can use the `auto-py-to-exe` library to build the client or the admin panel.
